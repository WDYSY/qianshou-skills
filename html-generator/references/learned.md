# html-generator 踩坑记录

## 2026-08-05 · 本地 vendor 里的 echarts.min.js 中段损坏

**症状**：pages 上生成的可视化页面所有 `echarts.init(...)` 图表容器空白（KPI/文字/emoji 都正常，就是 canvas 一个不出）。浏览器控制台没有明显的加载错误，`typeof echarts === 'undefined'`。

**排查**：
1. curl 拉 `<PAGES_REPO>/static/vendor/echarts.min.js`（本助手 pages 仓库下的 vendor 目录） 返回 200，Content-Length 正常，UMD wrapper 头也在（`!function(t,e){"object"==typeof exports&&...})(this,(function(t){"use strict";...})`）
2. 但 `echarts.min.js` 加载完执行后 `window.echarts` / `globalThis.echarts` 都是 undefined —— 说明脚本执行过程中出错了
3. 拉 jsdelivr 的 5.4.3 干净版 md5 对比：
   - 本地/pages vendor：`f644de40893e1d72850b5651576fdfd2`
   - jsdelivr CDN：`38588d6b8c7c30b9941c28c01b389b88`
   - **大小完全相同（1024740 bytes）**，但从**字节 172032 开始**内容不同
4. 推测是某次编辑器/传输过程把中段代码换错了（大小碰巧一致，内容替换成了另一段），静默污染

**修复**：从 `https://cdn.jsdelivr.net/npm/echarts@5.4.3/dist/echarts.min.js` 下载覆盖 `ui/static/vendor/echarts.min.js` 和 `public/static/vendor/echarts.min.js`，两处都要同步。

**预防**：
- vendor 目录里的第三方脚本应该保持只读 / 校验 md5，不要用编辑器打开（可能有静默编码转换）
- 新增或更新 vendor 时应该记录官方 md5，定期校验
- pages 发布脚本的 vendor URL 重写走的是 `../../static/vendor/xxx`，本地 `ui/static/vendor/` 是真北源头，`public/static/vendor/` 是 pages 部署副本，两处要保持一致

**兜底方案**：如果本地 vendor 又坏了，先在 HTML 里改成 `https://cdn.jsdelivr.net/npm/echarts@5.4.3/dist/echarts.min.js` 让页面能用，再单独修 vendor。


## 视觉自检降级规则

- **无视觉能力时的降级**：若当前模型不支持识图，不要发起模型切换投票或阻塞等待。直接跳过视觉自检，改做基础 HTML 结构校验（标签闭合、容器非空等），确认无误后发布页面，并在回复中简要说明已跳过视觉自检。

_— 来源：Meining She（2026-09-08）_


## 看板局部修改与多产线文案规则

- **局部修改后的全页面回归审查**：修改看板局部元素后，必须对全页面做回归审查——包括页脚口径/时间窗口、全局汇总与各业务线求和对齐、字段口径与隐藏指标的一致性——防止局部修复引入全局不一致。
- **多产线指标卡片帮助文案差异化**：当看板包含多条产线且各产线计数粒度不同时，每个指标卡片的帮助文案（问号）须按产线分别生成，写清计数组合粒度、膨胀倍数、回溯窗口差异，并注明数据源表名与口径边界，避免用户跨产线直接比较条数规模。

_— 来源：GuanWen Yan、阎冠文（2026-09-18）_


## 数据与素材合规规则

- **导入同源同口径跨期数据时**：对比新旧表数值差异，在页面中向用户标明差值。
- **内嵌第三方平台图标时**：在页面中附上来源出处与官方使用限制声明。

_— 来源：GuanWen Yan（2026-10-16）_


## 生成与自检

- **页面里所有"计数类"展示必须由数据源变量渲染（JS 插值），不要硬编码字面量**。硬编码的数字在数据更新时不会跟着变，产生"图表对、按钮错"的自相矛盾页面。
  - 2026-10-13 实测：eSIM 周报连续 4 版出现同一个问题——筛选按钮 `<span class="cnt">` 里的灯色计数（Red/Yellow/Green）是硬编码的，每次数据更新后仍是上一版的值（如数据已是 6/21/53，按钮仍显示 8/22/50），而同一页面的 `DATA` 对象和图表是对的。
  - 判断方法：生成后 grep 页面里所有 `<span class="cnt">`、徽章数字、章节标题里的计数（如"Red 产品（N 个）"），与数据源逐一比对；两者不一致即为脱节。
  - 根治做法：把计数统一放在一个配置对象里（如 `DATA.green / DATA.yellowCount / DATA.redCount`），DOM 渲染时全部从这里取值；章节标题里的计数也由 JS 动态写入。
  - 交付前自检清单：① 筛选/切换按钮计数 ② 章节标题计数 ③ 指标卡数值 ④ 表格行数 ⑤ 图表 series 名——五项与数据源一致才可发布。


## 视觉自检降级强制阻断

**无视觉能力进入截图自检时**：直接跳过视觉自检做基础结构校验并发布，禁止发起模型切换投票阻塞。

_— 来源：Weibing Li（2026-10-19）_


## 发布目录 URL 404 降级

**发布脚本返回目录 URL 访问 404 时**：直接改用同路径下的 `index.html` 链接交付给用户。

_— 来源：Weibing Li（2026-10-19）_


## 源数据字段缺失与聚合降级规则

- **源数据缺失关键维度字段（如年份）**：须先向用户确认取值再标注，不可自行假设。

_— 来源：Min Yan（2026-10-21）_

- **将多记录详情页改为聚合视图**：聚合维度须保留逐条明细下钻入口，分析数据不可丢。

_— 来源：GuanWen Yan（2026-10-21）_


## 图表选型与误读降级规则

- **多系列折线交叉过多或易误读时**：改用热力图或并列条形图，异常值用警示色单独标出。

_— 来源：Wei Song、Hindy Huang（2026-10-22）_


## 可视化与跨期报告口径标注规则

- **样例或采样数据生成的可视化**：在页面上显式标注采样口径与数据来源。
- **跨期同比报告**：在页面显著位置标注星期或日历错位。

_— 来源：Yuanyuan Ni、Rachel Hong（2026-10-20）_
